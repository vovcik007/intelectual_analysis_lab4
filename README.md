## Запуск після клонування

Потрібен **Python 3.12**. Середовище й локальний Python не зберігаються в Git: на новому комп’ютері їх слід створити заново.

У PowerShell із кореня репозиторію:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
& .\.venv\Scripts\python.exe -m ipykernel install --prefix .\.jupyter --name lab4 --display-name "Python (ЛР4)"
```

Відкрий `ЛР4_Лопатін_12.ipynb` у VS Code з розширеннями **Python** і **Jupyter**, вибери ядро з `.venv\Scripts\python.exe` та виконай **Run All**. Робоча папка — корінь репозиторію.

Альтернативний запуск JupyterLab у браузері:

```powershell
.\Відкрити_ноутбук.cmd
```

Запуск Orange:

```powershell
.\Відкрити_Orange.cmd
```

Якщо File у потоці Orange не знаходить початковий локальний шлях, вибери `ряд_для_orange.csv` із поточного клону. У Select Columns ціль — **price**, часова змінна — **date**. У Difference та Seasonal Adjustment після відкриття може знадобитися знову виділити price й натиснути Apply. Для оцінювання задано **ARIMA(1,1,1), 7 folds × 3 forecast steps**.

## Результати та обмеження

- Сітка має 46 місяців і 45 первинних вимірів; серпень 2017 заповнений лінійною оцінкою **6.55335 грн/кг**.
- Найкращий базис за об’єднаним RMSE — **середнє: 2.388983 грн/кг**. ARIMA(1,1,1) має **2.840572 грн/кг** і цього базису не перевершила.
- Однаково названі метрики Orange і Python зіставлено за фактичними формулами. Особливості POCID і міжфолдових стиків пояснено в ноутбуці та конспекті.

Автоматичні перевірки й знімки Qt-віджетів отримані асистентом у режимі offscreen. Це не засвідчує особисту перевірку студентом; особисті поля декларації та висновки заповнюються за фактично виконаними діями.

Дані надано разом із методичкою; зазначене в ній первинне джерело — **World Food Programme, Global Food Prices Database, CC BY-IGO**. Формули Orange перевірено за встановленою версією **Orange3-Timeseries 0.6.3**; її код доступний у [репозиторії biolab/orange3-timeseries](https://github.com/biolab/orange3-timeseries). Локальна копія functions.py повторно створюється ноутбуком і не дублюється в Git.
