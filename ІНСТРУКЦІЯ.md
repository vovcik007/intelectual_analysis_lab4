## Що тобі зробити перед здачею

**Можна працювати прямо у VS Code.** Відкрий `ЛР4_Лопатін_12.ipynb`, натисни **Select Kernel** у правому верхньому куті → **Python Environments** → Python із `.venv\Scripts\python.exe` цієї лабораторної. Якщо середовища немає у списку, виконай **Python: Select Interpreter → Enter interpreter path** через Ctrl+Shift+P і вибери `D:\volodya_uni\intelectual_analysis\lab_4\.venv\Scripts\python.exe`, потім повернися до вибору ядра ноутбука. Для інтерфейсу ноутбуків потрібні розширення Microsoft **Python** та **Jupyter**. Після вибору ядра натисни **Run All** або запускай клітинки по черзі через Shift+Enter. Окремий запуск JupyterLab через `.cmd` для цього не потрібен. Orange залишається окремою програмою.

У `.vscode/settings.json` задано локальний Python як типовий інтерпретатор проєкту; якщо ядро вже було обрано раніше, його потрібно перемкнути у самому ноутбуці.

Варіант із браузером нижче також доступний. Службові runtime-файли він тепер створює в новій тимчасовій папці поточного користувача, щоб не використовувати файли з правами sandbox-користувача.

Якщо `.cmd` відкривається як текст у VS Code, виконай його у вбудованому терміналі PowerShell. Відкрий **Terminal → New Terminal** і введи:

```powershell
cd D:\volodya_uni\intelectual_analysis\lab_4
.\Відкрити_ноутбук.cmd
```

Для Orange зручно відкрити ще один термінал і виконати:

```powershell
.\Відкрити_Orange.cmd
```

Префікс `.\` означає «виконати файл із поточної папки». Просте відкриття вкладки `.cmd` не виконує команд. Якщо браузер автоматично не відкрився, скопіюй із термінала повне посилання `http://localhost:.../lab?token=...` у браузер. Термінал Jupyter залишається зайнятим, поки сервер працює; для інших команд використовуй нову вкладку термінала. Для завершення роботи Jupyter натисни Ctrl+C у його терміналі й підтвердь зупинку.

**Не копіюй вміст `.cmd` у PowerShell.** Рядки `@echo off`, `cd /d` та `if errorlevel` написано для іншого командного інтерпретатора — cmd.exe. Їх вставлення у PowerShell спричиняє повідомлення `Unexpected token 'off'`, `Unexpected token 'launch_lab.py'` та `Missing '(' after 'if'`. Виклик `.\Відкрити_ноутбук.cmd` передає весь файл потрібному інтерпретатору. Також можна запустити Python безпосередньо з PowerShell:

```powershell
& .\.venv\Scripts\python.exe .\launch_lab.py --notebook
```

Для Orange відповідна пряма команда:

```powershell
& .\.venv\Scripts\python.exe .\launch_lab.py --orange
```

Детальний порядок навчання з прив’язкою до завдань — у **`ПЛАН_ОПРАЦЮВАННЯ.md`**.

Для підготовки до захисту користуйся **`ПОЯСНЕННЯ_ДО_ЗАХИСТУ.md`**: 14 стислих розділів із результатами перевірок, їх інтерпретацією та необхідною теорією. Код і коментарі до всіх 18 кодових клітинок залишено окремо в **`РОЗБІР_КОДУ_ЛР4.md`**. Нумерацію читання в плані узгоджено з короткою версією.

1. Двічі клацни **`Відкрити_ноутбук.cmd`**. Відкриється JupyterLab у браузері. Залиш консоль відкритою, доки працюєш. Перевір ПІБ, групу та номер 12; ядро — **Python (ЛР4)**.
2. Переглянь завдання послідовно. У меню Kernel обери **Restart Kernel and Run All Cells**. Дочекайся завершення та збережи Ctrl+S. Усі висновки з числами містяться у виводах кодових клітинок, а рецензія — у Markdown завдання 9.
3. Двічі клацни **`Відкрити_Orange.cmd`**. Відкриється підготовлений потік. У цій версії **Form Timeseries** — це віджет **As Timeseries** із методички. Не треба заново встановлювати Timeseries.
4. Якщо File не знаходить CSV, відкрий у ньому **`ряд_для_orange.csv`** з цієї папки. У Select Columns мають бути **price → Target**, **date → Meta**; date має тип Time. Не змінюй вихідний CSV.
5. Відкрий Line Chart після Interpolate: графік має відповідати завданню 3. У Difference **виділи price**. У Seasonal Adjustment **виділи price**, перевір **12 / additive** і натисни **Apply**. Ці старі віджети можуть скидати виділення після повторного відкриття — це перевірено. У нижньому Line Chart вибери **price (season. adj.)**. У другій корелограмі перевір, що вибрано **Δprice**, а не price.
6. Відкрий ARIMA Model: **p=1, d=1, q=1**. Відкрий Model Evaluation: **7 folds**, **3 forecast steps**, **Apply**. Порівняй **верхній рядок**, без `(in-sample)`: RMSE **2.841**, MAE **1.196**, MAPE **0.373**, POCID **60.0**. Якщо встановиш іншу версію бібліотек, можливі відмінності — спочатку перевір версії й параметри, не підганяй числа.
7. За потреби викладача зроби **власні знімки робочого столу** цих вікон. Наявні PNG — реальні автоматичні знімки віджетів; вони вже вставлені в ноутбук. Для перевірки помилки встанови 20 folds, натисни Apply, потім обов’язково поверни 7. Збережи потік Ctrl+S.
8. У завданні 3 допиши **власну** відповідь, що саме було неочікуваним. У декларації ШІ заповни три позначені поля: що змінив, що перевірив самостійно та які помилки помітив. Напиши лише те, що справді зробив. Прочитай `ПОЯСНЕННЯ_ДО_ЗАХИСТУ.md`, перевір розуміння коду, постав фактичні дату й підпис.

## Чому в потоці є додаткові Python Script

Основний аналіз і прогноз виконують штатні віджети Orange. Скрипти лише узгоджують дані на двох бічних гілках:

- Після Difference перша різниця не визначена. Скрипт вилучає перший рядок, щоб ACF будувалася на тих самих 45 різницях, що й Python; жодної ціни для ARIMA він не змінює.
- Прямий Seasonal Adjustment у Timeseries 0.6.3 повертає **`variable date is not in domain`**. Є знімок цієї фактичної помилки. Скрипт передає ті самі 46 цін без зламаного посилання на часову змінну; Seasonal Adjustment виконує власне коригування. Наступний Form Timeseries повертає місячні дати з 01.03.2014. Код відкритий у віджеті, бібліотеки не редагувалися.

Якщо викладач вимагає потік без додаткових скриптів, покажи зафіксовану помилку та узгодь цей технічний обхід. Сам факт такої вимоги нам невідомий; методичка не забороняє додаткових віджетів.
